# Arc 05 — Conceptual / Causal Model Learning

## Mission shape

Learner should become able to reason from a compact causal or mechanism model instead of repeating a polished explanation.

## Candidate topics

Use one real topic such as:

- blockchain trust;
- distributed systems;
- attention / transformers;
- economic mechanism;
- philosophical distinction with operational consequences.

## Target capability

Explain the mechanism, discriminate it from a nearby wrong model, generate predictions, and transfer the model to a new scenario.

## S1 — expose the learner's generator

Use a prediction, contrast, or small scenario to reveal the learner's existing causal model.

Avoid asking for a generic definition when a discriminative probe can expose more.

If an analogy is useful, record what relation it carries and where it stops being valid.

## S2 — Feynman model debugging

Ask for an explanation only when it can reveal structure. Extract one high-leverage gap:

- unexplained jump;
- vague causal term;
- circular explanation;
- hidden assumption;
- borrowed terminology;
- conflation with a nearby mechanism.

Challenge one gap, then ask the learner to repair the model.

## S3 — representation / intervention

If useful, use a causal graph, state machine, mechanism diagram, or comparison table.

Require the learner to predict what changes under one intervention/removal/reordering. The diagram should support causal reasoning, not merely summarize nouns.

## S4 — transfer

Change the surface context while preserving the mechanism, or present a confusable mechanism and ask the learner to discriminate them.

Examples:

- decentralized coordination in a different protocol;
- failure modes in a different distributed system;
- attention-like weighted aggregation in a new context.

## Runtime questions

- Did the tutor mistake fluent paraphrase for understanding?
- Did an analogy become the learner's final model?
- Did Feynman turn into a ritual rather than model debugging?
- Did the learner generate predictions from the model?
- Did performance survive removal of the original terminology?

## Exit evidence

A strong arc ends with the learner independently explaining the mechanism, making a correct novel prediction, and rejecting or repairing a nearby incorrect model.
