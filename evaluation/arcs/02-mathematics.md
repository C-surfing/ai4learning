# Arc 02 — Mathematics / Dependency Repair

## Mission shape

Learner should become able to reason with a formal object while connecting it to the prerequisite structure that makes the formalism meaningful.

## Candidate target routes

Choose one real route, for example:

- vector → linear map → eigenstructure;
- limit → derivative → local linearization;
- vector → covector → differential.

Do not mix several routes in one arc.

## Target capability

Use the target concept independently, explain why its definition has the form it does, and survive a change of notation or representation.

## S1 — locate the hidden dependency

Begin from the learner's actual question or task. Probe only enough to determine whether the blockage is:

- prerequisite concept;
- notation;
- procedural fluency;
- wrong generative model;
- missing geometric/structural representation.

If a hidden prerequisite appears, revise the roadmap rather than forcing chapter order.

## S2 — retrieve + reconstruct

Ask the learner to reconstruct the decisive relation or derivation with less scaffolding. Avoid repeating the same wording.

Evidence should distinguish symbolic imitation from mechanism understanding.

## S3 — representation switch

Use one meaningful switch:

- geometric picture ↔ symbolic derivation;
- coordinate form ↔ invariant statement;
- matrix ↔ linear-map view;
- diagram ↔ proof argument.

Require the learner to translate or predict, not merely observe both.

## S4 — transfer / boundary

Change one assumption or boundary condition that reveals what the original result depended on.

Examples:

- remove differentiability;
- change basis/coordinates;
- alter dimension;
- present a counterexample to an overgeneralized rule.

## Runtime questions

- Did the roadmap change when prerequisite evidence contradicted it?
- Did the tutor use terminology as a substitute for mechanism?
- Did a visual representation expose structure or merely restate symbols?
- Did scaffolding recede after independent evidence?

## Exit evidence

A strong outcome includes independent reconstruction plus successful use after notation/representation change. One polished explanation is insufficient.
